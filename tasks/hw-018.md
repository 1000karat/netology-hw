### Задание 6
Скачайте docker образ hashicorp/terraform:latest и скопируйте бинарный файл /bin/terraform на свою локальную машину, используя dive и docker save. Предоставьте скриншоты действий .
#### 🔧 Решение
не копировал в /bin/terraform , т.к. установлен из репки.

```shell script 
docker pull hashicorp/terraform:latest
mkdir /tmp/terr
cd /tmp/terr
docker save hashicorp/terraform:latest -o /tmp/terr/terraform.tar
mkdir terr_extr && tar -xf terraform.tar -C terr_extr
cd /tmp/terr/terr_extr/blobs/sha256
tar -xf 7883237053cdad4bbd2ae1666f6d1477586e7302bff0a74f5e1906caa10b43d6
cd bin
/tmp/terr/terr_extr/blobs/sha256/bin/terraform --version
./terraform --verison
terraform --version
```

### Задание 6.1
Добейтесь аналогичного результата, используя docker cp.
Предоставьте скриншоты действий .
#### 🔧 Решение
```shell script 
docker pull hashicorp/terraform:latest
mkdir /tmp/terr_cp
cd /tmp/terr_cp
docker create --name terraform-temp hashicorp/terraform:latest
docker cp terraform-temp:/bin/terraform ./terraform
```
