```

```  

2. Ошибки:
```shell script
│ Warning: Value for undeclared variable
│ The root module does not declare a variable named "service_account_key_file" but a value was found in file "terraform.tfvars". If you meant to use this value, add a "variable" block to the configuration.
│ To silence these warnings, use TF_VAR_... environment variables to provide certain "global" settings to all configurations in your organization. To reduce the verbosity of these warnings, use the -compact-warnings option.
```

3. ответы
- preemptible = true - прерывание для экономии [ресурсов](https://yandex.cloud/ru/docs/compute/operations/vm-create/create-preemptible-vm).
- [core_fraction](https://yandex.cloud/ru/docs/compute/concepts/instance-groups/instance-template)=5 - это параметр, который указывает на гарантированную долю vCPU для узлов Managed Service for Kubernetes в Yandex Cloud. Также core_fraction — это ключ, который определяет базовый уровень производительности vCPU в конфигурации базовой виртуальной машины Yandex Compute Cloud.
