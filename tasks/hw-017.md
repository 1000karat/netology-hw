### Задание 4

В качестве ответа приложите скриншоты консоли, где видно все введенные команды и их вывод.

#### 🔧 Решение
1. Запуск контейнера centos
```shell script
docker run -d --name centos-container -v $(pwd):/data centos:8 tail -f /dev/null
```

2. Запуск контейнера debian
```shell script
docker run -d --name debian-container -v $(pwd):/data debian:stable tail -f /dev/null
```

3. Создание файла из контейнера centos
```shell script
docker exec -it centos-container bash -c 'echo "Hello from CentOS container" > /data/centos-file.txt'
```

4. Cоздание файла на хосте
```shell script
echo "Hello from host machine" > host-file.txt
```

5. Gросмотр файлов из контейнера debian
```shell script
docker exec -it debian-container bash
ls -la /data
cat /data/centos-file.txt
cat /data/host-file.txt
```

### Задание 5

В качестве ответа приложите скриншоты консоли, где видно все введенные команды и их вывод, файл compose.yaml , скриншот portainer c задеплоенным компоузом.

#### 🔧 Решение
1. Будет запущен compose.yaml, потому что Docker Compose ищет файлы в порядке приоритета:
- compose.yaml
- compose.yml
- docker-compose.yaml
- docker-compose.yml

📌 Скриншот:
![Скриншот](https://raw.githubusercontent.com/1000karat/netology-hw/refs/heads/main/img/hw-017-010.png)

2. compose.yaml
```yaml
include:
  - docker-compose.yaml

services:
  portainer:
    network_mode: host
    image: portainer/portainer-ce:latest
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
```

7. Появился warning о том, что изменился набор compose-файлов проекта или отсутствует ранее использовавшийся compose-файл. Docker Compose предлагает выполнить очистку (остановку) проекта.
