### Задание 1
<details>
<summary>Детали</summary>  

1. Изучите проект.  
2. Заполните файл personal.auto.tfvars.  
3. Инициализируйте проект, выполните код. Он выполнится, даже если доступа к preview нет.

#### 🔧 Решение
Для запуска проекта необходимо:  
1. Создать и заполнить `personal.auto.tfvars`, пример содержимого:
```
service_account_key_file = "authorized_key.json"
cloud_id                 = "ya-cloud-id"
folder_id                = "ya-folder-id"
```  
2. В `variables.tf` добавить переменную:
```
variable "service_account_key_file" {
type        = string
description = "key file"
}
```
3. В `providers.tf` заменить 
```
token = var.token
```  
на
```
service_account_key_file = var.service_account_key_file
```

4. Выполняемые команды:
```bash
$ terraform fmt
$ terraform init
$ terraform plan
$ terraform apply
```

### Задание 3
<details>
<summary>Детали</summary>  

1. Создайте 3 одинаковых виртуальных диска размером 1 Гб с помощью ресурса yandex_compute_disk и мета-аргумента count в файле disk_vm.tf .  
2. Создайте в том же файле одиночную(использовать count или for_each запрещено из-за задания №4) ВМ c именем "storage" . Используйте блок dynamic secondary_disk{..} и мета-аргумент for_each для подключения созданных вами дополнительных дисков.
</details>  

#### 🔧 Решение
1. Создать и заполнить `disk_vm.tf`.
```
variable "set_disk_vm" {
  type = object({
    name = string,
    size = number,
    type = string
  })
  default = {
    name = "dosk-vm",
    size = 1,
    type = "network-hdd"
  }
}

resource "yandex_compute_disk" "disk_vm" {
  count = 3

  name = "${var.set_disk_vm.name}-${count.index + 1}"
  size = var.set_disk_vm.size
  type = var.set_disk_vm.type
  zone = var.default_zone
}
```
2. VM:
```
   dynamic "secondary_disk" {
   for_each = yandex_compute_disk.disk_vm

   content {
   disk_id = secondary_disk.value.id
   }
   }
```

```

web-2 ansible_host=<внешний ip-адрес> fqdn=<полное доменное имя виртуальной машины>

main ansible_host=<внешний ip-адрес> fqdn=<полное доменное имя виртуальной машины>

```

**Удалите все созданные ресурсы**.
</details>
