## Основная часть
1. Создайте новый проект в teamcity на основе fork.
2. Сделайте autodetect конфигурации.
3. Сохраните необходимые шаги, запустите первую сборку master.

📌 Скриншот:
![Скриншот](https://raw.githubusercontent.com/1000karat/netology-hw/refs/heads/main/img/hw-022-01.png)

4. Поменяйте условия сборки: если сборка по ветке `master`, то должен происходит `mvn clean deploy`, иначе `mvn clean test`.  

**Build Configuration → Build Steps**, должен содержать 2 шага:
- Tests: teamcity.build.branch does not equal master, clean test
- Deploy (master): teamcity.build.branch equals master, deploy -DskipTests

📌 Скриншот:
![Скриншот](https://raw.githubusercontent.com/1000karat/netology-hw/refs/heads/main/img/hw-022-02.png)

5. Для deploy будет необходимо загрузить [settings.xml](./teamcity/settings.xml) в набор конфигураций maven у teamcity, предварительно записав туда креды для подключения к nexus.

```settings.xml
<settings xmlns="http://maven.apache.org/SETTINGS/1.2.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.2.0 http://maven.apache.org/xsd/settings-1.2.0.xsd">
  <servers>
    <server>
      <id>nexus</id>
      <username>admin</username>
      <password>admin123</password>
    </server>
    <server>
      <id>nexus-snapshots</id>
      <username>admin</username>
      <password>admin123</password>
    </server>
  </servers>
</settings>
```

6. В pom.xml необходимо поменять ссылки на репозиторий и nexus.
```xml
...
<version>0.0.4</version>
...
<url>http://158.160.75.177:8081/repository/maven-releases</url>
```

7. Запустите сборку по master, убедитесь, что всё прошло успешно и артефакт появился в nexus.

📌 Скриншот:
![Скриншот](https://raw.githubusercontent.com/1000karat/netology-hw/refs/heads/main/img/hw-022-03.png)

8. Мигрируйте `build configuration` в репозиторий.
- откройть настройки проекта: Projects → exTeamcity → Versioned Settings
- включить `Synchronization enabled`

📌 Скриншот:
![Скриншот](https://raw.githubusercontent.com/1000karat/netology-hw/refs/heads/main/img/hw-022-04.png)

9. Создайте отдельную ветку `feature/add_reply` в репозитории.

```java
public String sayHelloHunter() {
```
